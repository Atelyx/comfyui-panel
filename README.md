# ComfyUI

把本机 ComfyUI 嵌进 Atelyx 的**工作台插件**（`panel` 类型）：面板内挑工作流、调参数、排队生成、看实时进度并把结果存进仓库，另有面板内嵌 ComfyUI 原生的编排界面。

> **要求：Atelyx 0.5.0 及以上**（插件包格式：`package.json` + 入口默认导出 `apply(ctx)`）。

## 用法

插件提供两个面板：**ComfyUI**（工作流、生成、队列、结果）与 **ComfyUI 编排**（内嵌原生编辑器），在「添加面板」里分别添加，用 Atelyx 的面板标签切换。

工作流直接来自 ComfyUI 用户目录（`user/default/workflows/`），**无需导入**：

1. 在 **ComfyUI 编排**面板里编排并「保存」——工作流写进 ComfyUI 目录，几秒内自动出现在生成面板的列表里。
2. 在 **ComfyUI** 面板选工作流、调参数（表单按节点定义自动生成），点「生成」，结果进入下方画廊；点「保存」写入仓库附件。
3. 编排界面里保存的修改会被自动感知：当前工作流本地没改参数就静默重载，正在调参时会提示手动重载。
4. 「保存参数」把当前参数写回工作流文件（UI 格式只改 widget 值，结构与连线不动）；「重新加载」放弃本地改动、读回文件里的参数。

ComfyUI 目录里的工作流大多是界面格式；插件内置转换（规则与 ComfyUI 前端一致）后即可在生成面板调参与提交。个别含子图或无法识别节点的工作流不能在生成面板转换，会提示在编排界面打开。

## 连接

ComfyUI 默认拒绝跨站请求，而插件界面发出的请求属于跨站，因此**必须让它带 `--enable-cors-header` 启动**：由插件启动时该参数自动带上，自行启动时手动加（`python main.py --enable-cors-header`）。未带时连接会失败。

## 进程

设置里可选**托管**（插件启停）或**外部**（自行管理，插件只检测连接）。停止会结束整棵进程树；插件停用、卸载或应用退出时，Atelyx 也会自动收尾它启动的进程。

## 权限

| 声明 | 用途 |
| --- | --- |
| `shell` | 启动与停止 ComfyUI 进程（可改为「外部」不托管） |
| `state` | 保存插件设置 |
| `vault` | 把生成结果写入仓库附件目录 |
| `native` | 调用 Atelyx 的附件导入命令，把图片字节落进仓库（插件的文件写入通道只支持文本） |
| `notification` / `dialog` | 状态提示、选择目录与文件 |

工作流列表与文件读写走 ComfyUI 自身的 `/userdata` 接口，插件不做任何联网上传：所有请求都发往你配置的地址。
